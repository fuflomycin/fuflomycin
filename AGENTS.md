# Руководство для агентов

## Назначение

`fuflomycin` — русскоязычная база описаний препаратов. Это справочный проект, а не источник персональных медицинских рекомендаций.

## Архитектура данных

- Исходные данные: `src/homeopathy/`, `src/rsp/`, `src/fk/` — Markdown с YAML frontmatter.
- Генерируемые артефакты: `docs/homeopathy.json`, `docs/rsp.json`, `docs/fk.json` и `docs/img/`.
- Конвертеры: `src/homeopathy.js`, `src/rsp.js`, `src/fk.js`.
- `docs/index.html` — отдельная статическая страница; конвертеры её не изменяют.

Редактируйте данные и изображения в `src/`. Не редактируйте `docs/*.json` вручную: сборка перезапишет изменения.

## Категории

| Каталог | `section` | Обычная метка |
| --- | --- | --- |
| `src/homeopathy/` | `Гомеопатия` | `red` |
| `src/rsp/` | `РСП / Фуфломицин` | `orange` |
| `src/fk/` | `Негативный перечень ФК` | `red` |

`yellow` в РСП используют только если бесполезность зависит от формы выпуска.

## Работа с записями

1. Выберите категорию и создайте или измените `src/<category>/<slug>.md`.
2. Берите frontmatter из `src/.homeopathy`, `src/.rsp` или `src/.fk`.
3. `title` обязателен: записи без него не попадут в JSON.
4. Имя файла — латинский `kebab-case`; оно определяет публичный JSON `id` в `camelCase`. Не переименовывайте существующий файл без явной необходимости.
5. Указывайте проверяемые URL в `source`; не представляйте отсутствие данных как доказательство отсутствия эффекта.
6. Новые изображения кладите рядом с Markdown в `src/<category>/`; в `photo` и `gallery` используйте только имя файла.

Основные источники: РСП — Encyclopedia Pathologica, ФК — негативный перечень ФК РАМН, реестры РФ и РБ — для уточнения торговых наименований и регистрации.

## Сборка и проверка

```bash
npm run homeopathy
npm run rsp
npm run fk
npm run all
```

После изменения контента пересоберите затронутую категорию, проверьте `git diff docs/` и включите в изменение исходный Markdown, новые изображения и обновлённые артефакты `docs/`.

Проверьте, что новые `photo` и элементы `gallery` появились в `docs/img/`. Существующий Husky-конфиг может не запускать сборку автоматически, поэтому не полагайтесь только на pre-commit hook.
