# Аудит источников данных

## Порядок работы

1. Определи актуальные канонические файлы в `src/homeopathy/`, `src/rsp/` и `src/fk/`; JSON в `docs/` используй только как собранное представление.
2. Получи внешний источник и зафиксируй URL, дату доступа и явно указанные им оговорки.
3. Сопоставь названия с `title`, а альтернативные названия — с `other` и `mnn`. Учитывай транслитерацию, `ё/е`, регистр и торговые названия.
4. Подготовь отчёт в четырёх разделах:
   - новые отдельные записи;
   - дополнения к существующим записям;
   - дубли или противоречия в локальных данных;
   - неоднозначные совпадения, требующие ручной проверки.
5. Для каждого пункта укажи путь локального файла, внешний URL и краткое основание.

## Требования к выводам

- Не делай вывод об эффективности только по отсутствию препарата в одном источнике.
- Не предлагай автоматическое удаление или смену медицинской классификации без явного подтверждения.
- Перед изменением данных запроси подтверждение пользователя, если аудит был read-only.
- Для РСП используй страницу Encyclopedia Pathologica, указанную в `README.md`, если пользователь не назвал другой первичный источник.
